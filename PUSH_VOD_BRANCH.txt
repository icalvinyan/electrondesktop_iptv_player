WHAT'S NEW IN THIS BUILD
========================

1. VOD PLAYER NOW HAS ITS OWN CONTROL SET (separate from Live TV)
   The on-screen player overlay is shared between Live TV and VOD, but VOD
   playback works very differently from a channel feed — so its controls have
   been redesigned:
     • Removed the "stream strength" bars and "● LIVE" badge (not meaningful
       for on-demand video).
     • Removed the guide / favorite / copy-stream-URL buttons (Live-TV-only
       features).
     • Removed the flashing red dot on the status badge altogether — in BOTH
       the VOD and Live TV overlays.
     • The plain-text title is replaced by the movie/show's clearlogo artwork,
       and the channel-logo box is hidden.
     • Added a scrub/seek bar with elapsed/remaining time, click-and-drag to
       jump to any point in the video.
     • Left/Right arrow keys now skip ±10 seconds; pressing the same direction
       repeatedly in quick succession increases the jump size each time
       (10s → 20s → 30s → …), then resets after a short pause.
     • The on-screen prev/next buttons now act as rewind / fast-forward:
       each click bumps the speed (2x → 4x → 8x → 16x), then wraps back to
       normal playback. Pressing Play/Pause also resets to normal speed.

2. RICHER STREAM-PICKER INFO (size, codecs, runtime, seeders, languages, etc.)
   When choosing between multiple stream results for a movie, each option now
   shows the full metadata block providers like Torrentio/AIOStreams send —
   file size, video/audio codec tags (BluRay/HEVC/DV/Atmos/TrueHD/7.1…),
   bitrate, runtime, seeder count, age, source tracker, languages, and the
   full filename/path — instead of just a single summary line.

3. FIXED: PROVIDERS THAT RESOLVE STREAMS SERVER-SIDE (e.g. AIOStreams) NOW WORK
   Some providers — notably AIOStreams when you've linked your own Real-Debrid
   account to it — don't hand back raw torrent hashes; they return a direct,
   ready-to-play URL that they've already resolved through your debrid account.
   The app's pipeline previously only understood raw torrent-hash results and
   discarded everything else ("0 usable streams" even when dozens came back).
   It now recognizes both kinds of results: torrent-hash streams are still
   resolved through this app's own Real-Debrid connection as before, while
   provider-resolved direct URLs are played immediately, with no extra step
   (and without needing to share your Real-Debrid key with this app).

4. CARRIED OVER FROM THE PREVIOUS BUILD
   - No scraper is hardcoded — you choose your own providers in
     Settings → Stream providers (single add or bulk "repository" import,
     enable/disable, drag-to-reorder for fallback priority).
   - VOD nav cleanup (Home/Movies/Shows tabs in the VOD top bar, no Live-TV
     chrome while in VOD mode), fixed spotlight banner darkness, and
     Cloudflare-bypass activity logs to DevTools with an orange "[netFetch]"
     prefix.

DEBUGGING "nothing happens" / playback errors
==============================================
All VOD actions log to the DevTools console with a "[VOD]" prefix — card
clicks, spotlight updates, provider queries (one line per provider, e.g.
"[VOD] Querying provider: <name> <url>"), parsed-stream counts ("Parsed
results with usable streams: N / M"), Real-Debrid calls, and any JSON-parse
failures (which log the raw response so we can see what was actually returned,
e.g. an HTML error/Cloudflare page instead of JSON). Cloudflare-bypass attempts
show up as orange "[netFetch]" lines.

To open DevTools in the running app: View menu → Toggle Developer Tools, or
Cmd+Option+I. Click the Console tab, then click a movie card / Play, and copy
back any "[VOD]" / "[netFetch]" lines (especially red error lines) — that'll
show exactly where it's breaking, and for which provider.
